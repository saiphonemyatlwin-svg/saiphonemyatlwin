# Outlier Meta (Facebook/Instagram) Ads from English-Learning Apps: Ad-Level Catalogue (Nov 2026)

Compiled 2026-11-24. This extends `research_notes/Outlier ads English IELTS leadership/english_apps.md`. That file covers Praktika's "Gustavo" creator video, the AdManage summaries for Babbel, Preply and Speak, ELSA in Vietnam via Airbridge, and the Learna/Loora/Falou "Never say 'I'm fine, thank you'" cluster. Ads already listed there appear here only as one-line cross-references, with new data added where available.

Labels:
- **[VERIFIED]**: stated by the company or by Meta.
- **[3P-DATA]**: a third-party tracker read of the Meta Ad Library. The main source is Sprites.ai brand pages, which give the start date, end date, format and ad ID; most were read Oct 5–8, 2026, with totals updated Nov 19–23, 2026. AdManage, Upspring and Airbridge figures come from the earlier notes.
- **[OBSERVATION]**: my own inference.

Every "Library ID" resolves at `https://www.facebook.com/ads/library/?id=<ID>`.

Method limits:
- "Days active" is the run length the tracker reported at capture. For live ads it is a lower bound.
- "Versions" means the number of separate ad IDs a tracker listed with the same headline or copy. It is a lower bound because Sprites shows about 30–40 ads per brand.
- Meta's library does not publicly expose country targeting for commercial (non-EU) ads, so the target market is inferred from the copy language and labeled [OBSERVATION].
- Video length and first-3-second visuals were not available from text scrapes. See Gaps.
- During this session, admanage.ai would not resolve because the host is outside this session's allowed network domains. The Upspring/Adyntel Alexandria providers could not run because Firecrawl credits were exhausted. The catalogue therefore leans on Sprites.ai pages.

## Q1. Which ads have the longest run time and most versions per app? (Ranked catalogue)

### Takeaway
By run length plus version count, the strongest English-relevant outliers are:
- Preply's "Speak English Confidently" family: 1,643 variants, up to 254 days.
- Speak's French-market "Apprenez l'anglais 3,7 plus vite" (358 days).
- Falou's "🌍 Speak English in Just 10 Minutes a Day!" (346 days, still running).
- Promova's "Become an 😍Advanced Speaker😍 of English" (294 days).
- Loora's "Want to speak English fluently? Meet Loora" (189 days, still running).
- Praktika's multilingual "⭐️⭐️⭐️⭐️⭐️ Try Now" AI-tutor video (175 days, still running, cloned into JA, KO, FR, PT, ES, RU and DE).

A key correction to the earlier notes: Praktika's main Meta page (ID 104781132385804) has **50,001+ ads and 4,123 active**. The "22 ads" figure in the earlier file came from a secondary page (1235858642949786). Praktika is therefore one of the largest Meta advertisers in the category, not a small one.

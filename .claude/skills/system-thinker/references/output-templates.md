# Output Templates

Use these shapes. Drop any section that would be empty; never pad one to fill the template.

## Quick answer (fast path)

Aim for under 200 words.

```
**The problem:** [one question, with a metric and a deadline]

**Most likely cause:** [one sentence] - [fact / inference / assumption]

**Check first:** [the cheapest test that would prove this wrong, and how long it takes]

**Do this:** [the action, who owns it, by when]

**Watch:** [the one number that tells you it worked]
```

If the problem shows signs of recurring, add one line: "This looks like it may come back; say the word and I will map the system behind it."

## System brief (deep path)

Lead with the answer. A reader who stops after the first section should still know what to do.

```
## The short version
[Three to five sentences: what is really going on, the recommendation, and the first step.]

## The real problem
- As stated: [the user's framing]
- As I see it: [the reframed problem, and why the difference matters]

## The system
- Inside the boundary: [people, teams, flows, rules]
- Left out on purpose: [what and why]
- Behaviour over time: [the pattern in the key number]

## The map
[Text loop diagram: 5-8 variables, 2-3 loops, delays marked]

[Two or three sentences reading the map in plain words.]

## The pattern
[The archetype, if one fits, its trap, and its way out. Omit if none fits.]

## Where to push
| Leverage point | Why it matters | Level |
|---|---|---|
| ... | ... | [numbers / information / rules / goal / belief] |

## What could go wrong
- [Side effect or resistance, and how to handle it]

## Recommendation
- Do: [one course of action]
- First experiment: [small, cheap, within two weeks]
- Metric: [the number, and the delay before it should move]
- Review on: [date]
- Stop if: [the condition]

## What I assumed
- [Each assumption, so the user can correct it]

## This week
[One action the user can take in the next seven days.]
```

For a very large problem, give "The short version" and "This week" in the reply and offer the remaining sections on request.

# Video Scorecard: 10 components × 0–2 = /20

Score each: **0 = missing / broken · 1 = present but weak · 2 = strong, a model to copy**.

| # | Component | 2 points looks like | Common "lacking" pattern | Score |
|---|---|---|---|---|
| 1 | Idea (topic + angle) | Validated topic, angle you haven't heard before | Generic topic, obvious take, a list of facts | |
| 2 | Hook stack (0–1.5s) | Visual + spoken + text hooks fire together | Slow intro, "hi guys", logo, text repeats speech | |
| 3 | Promise (≤ 5s) | Viewer knows the payoff and why to stay | Never says where it's going | |
| 4 | Retention | Open loop + interrupt every 3–6s, no dead air | One static shot, long pauses, a sagging middle | |
| 5 | Payoff | Specific light-bulb moment by ~60% | Vague advice, payoff at the very end or never | |
| 6 | Proof | Shown, specific, contextual | Claimed authority, none, or borrowed | |
| 7 | Visual craft | Lit face, clean frame, intentional background | Backlit, messy, shaky, off-brand colours | |
| 8 | Audio craft | Clear voice, music low, SFX on beats | Echo, noise, music fighting the voice | |
| 9 | Text / captions | Burned-in, readable, in safe zone, highlights key words | No captions, tiny text, covered by UI | |
| 10 | Close + CTA | Tattoo line + one aligned action, loopable end | Fades out, no CTA, or 3 CTAs at once | |
| | **Total** | | | **/20** |

**Ship:** ≥ 15 · **Fix lowest component:** 12–14 · **Re-cut / re-shoot hook:** < 12

# Style breakdown — reference reel

Source: a 14 s Facebook reel (1080×1920, 30 fps) advertising a Claude video-
editing skill. The outer layer is an ad mock-up: a "CLAUDE EDITED THIS" header,
a "My timeline is empty." sub-line, a fake editor timeline with 0 clips /
0 keyframes / 0 masks, and a CTA pill. **The style worth learning is the edit
playing inside the phone**: a single podcast-style clip of a seated speaker
(hoodie, mic, purple-lit shelf) with motion graphics laid over it.

About 9 visual changes in 14 s, so a new idea every ~1.5 s, all cut to
spoken keywords.

## Design system

- **Palette:** graphite/near-black (#121214), silver-chrome gradient type,
  white; a single ice-blue accent (#5ec8ff-ish) for the glowing node, dot and
  arc. The colour in the source footage (purple set) is kept as is, with no grade.
- **Type:**
  - keywords: tall condensed grotesk, all caps, silver metal gradient with a soft
    drop shadow (Bebas Neue is a close free stand-in);
  - caption emphasis: high-contrast italic serif, lowercase (Instrument Serif
    Italic);
  - kickers: small tracked uppercase sans (Inter SemiBold).
- **Card surface:** vertical ribbed/fluted texture with a soft centre lift
  and a wide diagonal light band sweeping across.
- **Layout:** keywords sit at 15–25 % of frame height, captions at
  ~70 %. A brand mark sits in a rounded square at the top right.
- **Motion:** keywords scale 112 % → 100 % with an ease-out in ~0.4 s;
  captions fade up ~10 px; cards crossfade in ~0.2 s; the speaker gets a
  slow push-in that resets after each cutaway; diagram nodes appear one by
  one; the number rolls with ease-out and digits slide vertically.

## Why it works

1. Depth from the person matte makes a flat webcam/podcast shot look designed.
2. Each beat restates the spoken word as an image, which helps sound-off viewers.
3. Grey and chrome with a single accent reads as premium, and nothing competes
   with the speaker's own colour.
4. Cutaways hide jump cuts and reset attention without new filming.
